# SeatMate v19

v18の画面・列車進行表示・天気・Googleカレンダー連携を維持し、乗換の一括登録と検索リンクを追加したiPhone向けPWAです。

## 乗換の登録

画像またはテキストを読み取り、「乗換経路をまとめて登録」を選択します。列車ごとの駅・時刻・座席を確認し、最後にまとめて保存します。「前の列車を修正」で戻れます。保存上限は列車合計5件です。

同じ旅の行程、乗換待ち、登録発車時刻までの残り時間を表示します。実際に乗り換えたら「次の列車に乗った」ボタンで切り替えてください。座席確認履歴と推定は列車ごとに保持します。遅延・実際の乗車は検知しません。

## 公式検索リンク

- えきねっと：駅名・乗車日を入力する検索フォーム。
- e5489：予約・空席照会メニュー。「新規予約」から検索。
- スマートEX：公式ログイン画面。ログイン後「列車を検索」。
- JR九州：ネット予約の入口。必要に応じてログイン。

検索条件は自動入力しません。検索する駅を変更すると、コピー用駅名と出発時刻も更新します。座席確認だけなら購入を確定しないでください。IDの任意保存は端末内のみで、パスワードは保存しません。

## 検証

`npm install`、`npm test`で計算・抽出・乗換ロジックの34テストを実行します。
ブラウザ検証は `python3 -m http.server 8765` 起動後、`npm run test:browser`。
`SEATMATE_CHROMIUM_PATH` でChromium実行ファイルを指定できます。

390px幅のChromiumで一括保存、入力の戻り修正、中止、容量制限、履歴分離、乗換待ち、切替、再読み込み、個別編集、検索リンク、コピー表示、既存の列車シルエット・カレンダーボタンの維持を確認しています。iPhone実機と認証後の外部サイト操作は未検証。画像OCR処理はv18から変更していません。

GitHub Pagesの公開対象はリポジトリ直下の静的ファイルです。更新時には全アプリファイルを揃え、Service Workerのキャッシュ番号も更新します。端末保存データを消す必要はありません。
